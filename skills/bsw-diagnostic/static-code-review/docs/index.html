static-code-review 文档中心

这是 static-code-review 便携包的统一首页。它把当前文件 review、函数级 review、导入、校验、门禁和正式文档入口收拢到一个页面，方便用户和维护者各自找到最短路径。

  • 普通用户：当前文件用 Static Code Review Current File，函数级 review 用 Static Code Review Selected Function。
  • 系统：自动执行规则检查、AI 判断、结果融合和正式报告生成。
  • 维护者：优先看设计文档，理解规则、校验、回归和问题定位链路。

默认操作路径

  1. 先在 VS Code 中打开 static-code-review 文件夹，运行任务 Static Code Review Setup。
  2. 在 VS Code 中打开当前要审查的 .c 文件。
  3. 运行 VS Code 任务 Static Code Review Current File。
  4. 到 review-reports/ 查看正式 HTML 报告。

用户只需要完成前 2 个动作并保持 Kimi 网页登录；规则检查、AI 判断、结果融合和报告生成会在后台自动完成。

如果只审查某个函数，先在编辑器中选中函数，再运行 Static Code Review Selected Function。

常见问题

没有生成报告

先确认你已经在 static-code-review 文件夹里执行过 Static Code Review Setup，并且当前打开的是要审查的 .c 文件；当前文件场景重新运行 Static Code Review Current File，函数级场景先选中函数再运行 Static Code Review Selected Function。

报告内容不完整

通常是导入的 Kimi 回复不完整。重新复制完整回复后，再重新执行当前文件 review。

报告已经过期

如果源码在报告生成后又被修改，重新触发一次当前文件 review 即可。
